# Medalion Architecture

For this puprpose we used DBT and DUCK DB to store the data.

## Bronze

### Notes
- Seeds are CSV files that DBT uses to insert into DB tables.
- `+schema: bronze` sets the default schema for all seeds to be `bronze`
- `+quote_columns: false` This normalizes the names of the columns and dose not use names uisng quotes (") 
- `bronze: +enabled: true` Enables seeds under `bronze` folder name
- 
#### Code 

```yaml
seeds:
  your_dbt_project_name:
    +schema: bronze
    +quote_columns: false
    bronze:
      +enabled: true
```
